Claude Task Dashboard — Privacy Policy

Effective August 18, 2026

This page is a static dashboard that displays the output of the author's own scheduled tasks. It has no account, no sign-in, no server of its own and nothing to collect from a visitor.

What It Stores

Two preferences, in your browser's local storage: the theme you picked and the text size you picked. Nothing else is written, and neither one leaves your device. Clearing the site's browser data deletes both.

What Leaves Your Browser

Nothing. The page makes no network requests of its own — its Content-Security-Policy sets connect-src 'none', so it cannot. The task output it displays is published in this repository and loaded with the page itself. GitHub Pages serves it and, like any web host, sees the ordinary request information involved in serving a page.

What It Does Not Do

  • No analytics or usage-tracking scripts
  • No advertising or ad networks
  • No cookies, no accounts, no sign-in
  • No third-party code of any kind

Changes to This Policy

If this policy changes, the updated version will be posted here with a new effective date.
